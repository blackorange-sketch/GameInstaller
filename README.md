# GameInstaller

Android-додаток, який розпаковує інсталятори Windows-ігор (Inno Setup + архіви FreeArc, зокрема репаки) без Winlator.
Використовуйте лише власні легальні копії ігор.

## Як користуватися
1. Обрати папку з інсталятором (Setup.exe і Setup-*.bin).
2. Обрати папку призначення й ввести назву папки гри.
3. «Встановити». Розпаковка йде у фоні (сповіщення з прогресом).
Потрібен дозвіл «Доступ до всіх файлів» (unarc працює зі шляхами, не з SAF).

## Як влаштовано
- Kotlin читає заголовок Setup.exe (Inno 5.x): список архівів, пароль, назву папки.
- `libunarc.so` це виконуваний unarc (third_party/unarc, патч: AES-256/CTR + пароль), зібраний NDK у CI й покладений у jniLibs; запускається з `nativeLibraryDir`.
- Перевірено на репаку C&C 3 (lzma lc8 + aes). srep/precomp не підтримуються (в основних архівах репаку їх немає).

## Обмеження
- Лише arm64. Словник LZMA до 700 МБ: потрібна вільна пам'ять.
- Файли, що лежать у самому Inno-контейнері (Setup-1a.bin: фікси, ini), поки не розпаковуються (потрібен innoextract).

## Збірка
GitHub Actions (.github/workflows/build.yml) збирає APK (артефакт GameInstaller-debug).
Проєкт написано без запуску Android SDK, тож перша збірка може потребувати дрібних правок.
